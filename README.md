# ⚖️ Сайт адвоката Шайдорова М.С. (MVP)

Прототип корпоративного сайта для юридической практики. Реализован полный цикл: от адаптивной вёрстки и бэкенда до админ-панели, защиты от спама и кастомных страниц ошибок. Проект находится на стадии **MVP** и готов к первичной демонстрации и сбору обратной связи.

## 📌 Статус
✅ **MVP / Прототип** — рабочий продукт с базовой архитектурой.  
🔄 В активной разработке: планируются доработки по контенту, аналитике и оптимизации под продакшен.

## 🛠️ Технологический стек
| Компонент | Технология |
|-----------|------------|
| Backend | Python 3.10+, Django 5.x |
| Frontend | HTML5, Tailwind CSS 3, Vanilla JavaScript |
| База данных | SQLite (для этапа MVP) |
| Управление зависимостями | `uv` |
| Конфигурация | `django-dotenv`, `whitenoise` |

## ✨ Реализованный функционал
- 📱 Полностью адаптивная вёрстка (Desktop / Tablet / Mobile)
- 📝 Форма заявки в модальном окне с валидацией, индикатором загрузки и защитой от двойных кликов
- 🛡️ Базовая защита от спама: honeypot-ловушка, rate-limit (сессии), нормализация телефона
- 🖼️ Карусель благодарственных писем с динамической генерацией индикаторов и привязкой к контенту из БД
- 🎨 Кастомные страницы ошибок `404.html` и `500.html` (автономные, без зависимостей от контекста Django)
- ⚙️ Админ-панель для управления отзывами, письмами, заявками и страницами
- 🔒 Вынесение секретных ключей и настроек окружения в `.env`

## 🚀 Локальный запуск
Для работы требуется `uv` и Node.js (для сборки Tailwind).

# 1. Клонирование и переход в папку
git clone <repo-url>
cd advocate-shaydorov

# 2. Создание окружения и установка зависимостей
uv venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
uv pip sync requirements.txt

# 3. Настройка окружения
cp .env.example .env  # или создайте .env вручную (SECRET_KEY, DEBUG=True)
python manage.py migrate

# 4. Сборка стилей (в отдельном терминале)
npm install
npx tailwindcss -i ./src/input.css -o ./static/css/main.css --watch

# 5. Запуск сервера
python manage.py runserver
Сайт будет доступен по адресу `http://localhost:8000`
