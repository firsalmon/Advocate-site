# MVP сайта для адвоката

Этот репозиторий содержит MVP сайта, который был разработан для клиента.

## Статус проекта: АРХИВИРОВАН

Клиент отказался от проекта после получения прототипа. Проект не был запущен в продакшен.

## Причины архивации

- Клиент не предоставил обратную связь после показа прототипа
- Клиент отказался от идеи сайта

## Примечание

Этот код остается в репозитории как пример работы и может быть использован для других проектов.
